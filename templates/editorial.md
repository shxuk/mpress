# 公众号排版模板：样式、语法与参数

全文首个 `#` 一级标题在推送时自动剥除，仅用作公众号文章主标题；画布固定白底 `#ffffff`，默认字体栈为无衬线系统黑体。

## 01 基础排版与文字

正文使用 `16px`，行高 `1.75`，字距 `0.01em`，主墨色 `#111819`。**中文边界加粗**直接写 `**文字**`，字重 `700`。行内代码写法为 `` `code` ``，字号 `0.88em`，浅灰底 `#e8eeee`，圆角 `3px`。

### 三级小节标题

三级标题原文写法为 `### 标题`，字号 `17px` 粗体，行高 `1.45`，左侧 `3px` 墨色 `#111819` 竖线，左内边距 `10px`。

- 无序列表原文写法为 `- 项目`，左缩进 `1.4em`，条目间距 `0.35em`。
- 列表字色统一为 `#111819`。

1. 有序列表原文写法为 `1. 项目`。
2. 与无序列表保持相同缩进与行距。

## 02 提示块、引文与代码

> TIP 提示块
>
> 浅底 `#f5f7f7`，左 `3px` 墨青 `#007275` 竖线，标签 `10px`，标题 `15px` 粗体，正文 `14px` 行高 `1.75`。原文写法：`> TIP 标题` 或 `:::tip[标题]`。

> NOTE 注释块
>
> 浅底 `#f5f7f7`，左 `3px` 次要灰 `#5d6667` 竖线，正文 `14px`。原文写法：`> NOTE 标题` 或 `:::note[标题]`。

> WARNING 警告块
>
> 浅红底 `#f7f5f5`，左 `3px` 警告红 `#a91611` 竖线，正文 `14px`。原文写法：`> WARNING 标题` 或 `:::warning[标题]`。

> IMPORTANT 重要块
>
> 浅底 `#f5f7f7`，左 `3px` 墨色 `#111819` 竖线，正文 `14px`。原文写法：`> IMPORTANT 标题` 或 `:::important[标题]`。

> 普通引用不加边框和底色，按 `16px` 正文段落输出。原文写法：`> 普通段落`。

> 长引使用衬线体 `17px`，行高 `1.8`，左侧 `2px` 墨色 `#111819` 竖线；末行 `——` 开头为 `12px` 右对齐出处（颜色 `#5d6667`）。
>
> —— 原文写法：`> 引文` 末行加 `> —— 出处`

```bash
# 代码块：浅底 #f5f7f7，左 3px 灰竖线 #5d6667，代码 14px，行高 1.75，语言名 10px 大写角标
node scripts/wechat.mjs push templates/editorial.md
```

# 一级标题（后续篇章分隔）

非首个 `#` 一级标题放在篇章分隔处，字号 `24px` 粗体，行高 `1.3`，底部 `1px` 墨色 `#111819` 实线收住。
