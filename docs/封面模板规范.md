## 2. 1:1 正方形小图裁切规范（微信公众号官方对齐）

微信公众号后台与手机客户端展示（朋友圈转发卡片、次条图文、部分搜索会话）强制需要一张 **1:1 正方形缩略图**。

1. **截取定位**：
   - 裁切框精准锁定在封面图右侧的**数据规格卡片区域**（避免左侧大标题文字被腰斩切断）：
     - 横向范围：`x = 1280 ~ 1780`（宽度 500px）
     - 纵向范围：`y = 50 ~ 550`（高度 500px）
   - 画面完整包含：左侧 1px 分隔垂直线、`AUTHOR / 出品`、`ARCHIVE / 存量`、`STATUS / 坐标` 以及背景的水印微纹印章。
2. **微信 API 自动注入**：
   在向微信新建/更新草稿接口推送时，必须且已自动注入坐标参数（归一化浮点数）：
   - `pic_crop_1_1: "0.711111_0.065274_0.988889_0.718016"`
   - `pic_crop_235_1: "0_0_1_1"`
   无需在公众号后台手动拉动裁剪框，系统自动对齐。
3. **本地正方形图片留档**：
   每次生成文章封面时，自动在产物目录切出并保存：
   - `head-square-500x500.png`
   - `head-square.png`

## 3. 真实数据与防漂移原则（Anti-Drift Principles）

1. **严禁 AI 编造或估算文案**：
   - 没有副标题就留空，绝不允许 AI 擅自提炼或虚构引语（如“当知识的半衰期缩短到两周”等臆造内容）。
2. **真实字数统计口径**：
   - **严禁使用模糊的“X.X 万字”**，统一展示为真实千分位数字 `${totalChars.toLocaleString()} 字`；
   - 扫描统计时，**必须显式排除 `.guide_backup` 或任何 `backup` / 隐藏目录**，避免重复计算历史归档；
   - **书籍详情页（`BookHero`）**：展示该专著全部正文章节的真实字数之和（如 codingbook 为 `58,940 字`，ai-seo 为 `46,338 字`）；
   - **公众号封面规格栏（`ARCHIVE / 存量`）**：使用博客全站所有正式文章（当前 58 篇）的纯中文字数总和（当前为 `106,766 字总结`）；
   - 统计基准脚本：`pnpm count:words`（源码位于 `scripts/count-article-words.mjs`），产物位于 `.generated/article-word-counts.json`。
3. **坐标天数真实递增**：
   - `STATUS / 坐标`：`DAY ${runningDays} · 推进中`，严格根据 `src/config/siteConfig.ts` 中的 `siteStartDate: "2026-11-09"` 与当前时间毫秒差动态计算，真实反映项目演进。
